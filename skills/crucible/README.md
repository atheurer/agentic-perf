# Crucible subject context

Retrieve Crucible guidance through the skill gateway:

```python
get_skill_context(subject="harness/crucible", operation="bootstrap")
```

Read the returned entrypoint refs and follow their documentation pointers.
The gateway combines applicable private organization guidance with
phase-appropriate upstream or installed-software references. Organization
sources are administrator-configured; their contents are maintained outside
this public repository.

Version-specific facts require the applicable installed or upstream references.
Report missing documentation as unavailable; do not infer behavior from retired
local copies. This directory contains no active Crucible skill document bundle.
