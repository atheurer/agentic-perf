# Crucible result review workflow

Review the user's stated objective and compare it with the measured result.
Use the ticket's result summary and artifacts first, then retrieve only the
additional benchmark or system data needed to answer the question. Use current
controller documentation and live metric metadata for metric definitions,
units, host mappings, and collection details; do not treat remembered defaults
or a generic example as proof about this run.

Separate observations from explanations. Cite the sample, time period, host,
metric, and tool evidence that supports each conclusion. Label an explanation
as an inference when the evidence does not establish it. If the requested
comparison cannot be made from available artifacts or source metadata, state
what is missing and ask for clarification rather than filling the gap with a
networking or hardware assumption.
