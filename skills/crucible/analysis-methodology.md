# Crucible analysis methodology

Use the evidence already attached to the ticket before requesting a new
benchmark. Identify the question being tested, the relevant run or artifact,
and the comparison that would distinguish the competing explanations.

Use available run metadata, artifact readers, prior-ticket results, and
configured data-source tools. Check that compared runs use compatible
workloads, endpoints, software versions, and measurement windows. Separate
observations from interpretation, cite the run IDs or artifact paths that
support each finding, and call out missing or conflicting evidence.

Conclude only when the available evidence answers the ticket's question. If a
new measurement is needed, state which uncertainty it should resolve and
suggest only the parameters needed to make that comparison. Do not infer a
result from missing data.
